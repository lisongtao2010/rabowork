# PdfPreviewForm（PDF 预览窗口）功能说明

> 所属项目：`MSIFAITOOLS`（.NET Framework 4.8 / WinForms / AnyCPU）
> 源文件：`PdfPreviewForm.cs`、`PdfPreviewForm.Designer.cs`、`Services\PdfTextSelection.cs`
> 主程序：`MSIFAITOOLS\bin\Debug\MSIFAITOOLS.exe`
> 更新日期：2026-10-27

---

## 1. 一句话概要

**PdfPreviewForm** 是 MSIF AI 工具里的独立 PDF 预览窗口：用 **pdfium** 把 PDF 页面渲染成位图显示，
用 **PdfPig** 提供文字坐标，因而既能像图片一样翻页、缩放、拖动画布，也能像 PDF 阅读器一样
**拖拽选择文字并复制**。

特色操作：

| 操作 | 效果 |
|------|------|
| **Ctrl + 鼠标滚轮** | 以**鼠标所在位置为中心**放大 / 缩小（缩放后光标下的内容不动） |
| **✋ 拖动** 按钮 | 开启后用**左键拖动画布**（抓手手感），不再触发选字 |
| **按住鼠标中键拖动** | 任何模式下都能临时拖动画布，松手即退出 |
| 鼠标滚轮 / Shift + 滚轮 | 纵向 / 横向滚动画面 |

本窗口**只做显示**，不会修改 PDF 文件。

## 2. 在工具中的位置（调用关系）

预览窗口不是主界面的一部分，而是由主窗口按需创建、长期复用的独立窗口：

```
Form1（主窗口）
  ├─【选中即预览】勾选框开启 + 分类结果列表当前行变化 → ShowPdfPreview(item, false)   ← 不抢焦点
  ├─ 双击分类结果某一行（「分类」列除外）              → ShowPdfPreview(item, true)    ← 前置窗口
  └─ 点【预览 PDF】按钮                              → ShowPdfPreview(item, true)    ← 前置窗口
        └─ 首次：new PdfPreviewForm() → Owner = Form1 → 挂 FormClosed → Show()
           之后：复用同一实例 → ShowPdf(item.FilePath)
```

| 行为 | 说明 |
|------|------|
| 首次预览 | 新建窗口，`Owner = Form1`（始终浮在主窗口之上），`Show()` 非模态显示 |
| 切换到另一个 PDF | 复用同一窗口，直接换文档（页号回到第 1 页，缩放回到「适合宽度」） |
| 再次预览**同一个** PDF | 不重新加载：只还原最小化、`Activate()` 前置窗口，**保留当前页与缩放** |
| 「选中即预览」 | 同一文件不会重复触发（`_lastAutoPreviewKey` 去重），键盘上下移动列表行即可快速浏览 |
| 关闭预览窗口 | `Form1._previewForm` 置空，下次预览重新创建 |
| 关闭主窗口 | 一并 `Close()` + `Dispose()` 预览窗口，释放 PDF 文件句柄 |

## 5. 缩放

### 5.1 三种缩放模式（`PdfScaleMode`）

| 模式 | 进入方式 | 缩放比例计算 |
|------|----------|--------------|
| `FitWidth`（默认） | 加载新 PDF 时、点「适合宽度」 | `(画布宽 - 24) / 页面宽(点)` |
| `FitPage` | 点「适合页面」 | `min((画布宽 - 24) / 页面宽, (画布高 - 24) / 页面高)` |
| `Custom` | 放大 / 缩小 / 实际大小 / **Ctrl+滚轮** | 使用 `_zoom` 原值（被夹在 0.1 ~ 6.0） |

- 「100%」的含义是 **96 DPI 下的实际大小**：`BaseScale = 96 / 72 ≈ 1.3333`，
  即 1 个 PDF 点（1/72 英寸）显示成 1.3333 像素。状态栏和 `lblZoom` 显示的都是 `zoom / BaseScale × 100`。
- 窗口尺寸变化只在 `FitWidth` / `FitPage` 模式下重新计算；`Custom` 模式下保持用户设定的比例不动。

### 5.2 Ctrl + 滚轮：以鼠标位置为中心缩放

这是本窗口缩放的核心体验：**放大时光标下的那一点内容留在原地**（和 PDF 阅读器 / 看图软件一致），
而不是从页面中心放大。

```
① 记下鼠标处的「PDF 坐标」
     pdfX = (鼠标在画布中的 X - picPage.Left) / 旧 zoom
     pdfY = (鼠标在画布中的 Y - picPage.Top ) / 旧 zoom

② 按 1.15 倍（或 1/1.15）缩放并重新渲染页面位图

③ 反算滚动位置，让那个 PDF 点重新回到鼠标处
     内容坐标 = 页面显示位置 + 滚动偏移
     scroll.X = picPage.Left + scroll.X + pdfX × 新 zoom - 鼠标 X
     scroll.Y = picPage.Top  + scroll.Y + pdfY × 新 zoom - 鼠标 Y
     两项都夹到 ≥ 0
```

> ⚠ 注意：`picPage.Left / Top` **已经包含**了 `AutoScroll` 造成的位移（滚动后子控件被移到负坐标），
> 所以第 ①、③ 步都**不能**再额外加减滚动偏移，否则缩放中心会偏移。

实现细节：

| 细节 | 说明 |
|------|------|
| 缩放档距 | 每格滚轮 **1.15 倍**（滚轮向前）或 **1/1.15 ≈ 0.870 倍**（滚轮向后） |
| 锚点位置 | 鼠标在画布内 → 用鼠标点；鼠标不在画布内但按着 Ctrl → 用画布中心 |
| 滚动校正 | 设置滚动位置可能让滚动条出现 / 消失，从而改变可视区宽度，因此**最多循环校正 2 次**，直到滚动值稳定 |
| 页面小于视口 | 此时无法靠滚动改变位置，页面只能居中，缩放围绕中心进行（属正常行为，不报错） |
| 缩放后 | 页面保持居中或左上对齐（`LayoutPage`），**已选文字保留**（PDF 坐标不变，只有像素比例变化） |

### 5.3 缩放范围与渲染保护

| 参数 | 值 | 作用 |
|------|----|------|
| `MinZoom` | `0.1`（约 7.5%） | 缩放下限 |
| `MaxZoom` | `6.0`（约 450%） | 缩放上限 |
| `MaxRenderPixels` | `25,000,000` 像素 | 单页位图上限。超限时按 `sqrt(上限/实际)` 等比缩小后再渲染，避免一次申请过大位图导致内存暴涨 |

所有缩放入口（按钮、快捷键、滚轮、`ApplyZoom`）都会经过 `Clamp(zoom, MinZoom, MaxZoom)`。

## 6. 平移（拖动画面）

### 6.1 「✋ 拖动」按钮（工具栏第 9 位）

| 状态 | 表现 |
|------|------|
| 关闭（默认） | 按钮浅灰蓝、页面光标为默认箭头；左键用于选字 |
| 开启 | 按钮变**浅蓝高亮**、页面光标变**手形**、状态栏追加「　拖动模式：按住左键拖动画布」 |

- 点击按钮切换开关（`BtnPan_Click` → `SetPanMode`）；关闭时会立即结束正在进行的拖动。
- 拖动过程中光标始终保持手形；鼠标离开页面时若处于拖动模式或正在拖动，也不会被重置为箭头。

### 6.2 中键拖动（任何模式）

不需要切换按钮：**按住鼠标中键拖动**即可平移画面，松开中键结束。
适合在「选字模式」下临时挪动画面去找下一段文字。

### 6.3 抓手算法（内容跟着鼠标走）

```
按下：记录起始鼠标屏幕坐标 _panStartScreen、起始滚动偏移 _panStartScroll，picPage.Capture = true
移动：offsetX = _panStartScroll.X - (当前鼠标X - _panStartScreen.X)
      offsetY = _panStartScroll.Y - (当前鼠标Y - _panStartScreen.Y)
      pnlCanvas.AutoScrollPosition = (max(0, offsetX), max(0, offsetY))
松开：picPage.Capture = false，光标恢复正常
```

- 鼠标左移 80 px → 画面内容也左移 80 px（反方向滚动），即**鼠标移动多少，内容移动多少**。
- 全程用**屏幕坐标**（`Cursor.Position`）计算，因此鼠标拖出窗口边缘、拖到子控件之外仍然连续、不跳变。
- 滚动值被夹到 ≥ 0，不会出现负滚动（画布左上不会露白）。
- 没有惯性 / 惯性滑动延迟，松手即停。

### 6.4 与文字选择的关系

| 模式 | 左键 | 中键 |
|------|------|------|
| 普通模式 | 选字（拖拽 / 双击 / 三击） | 拖动画面 |
| **✋ 拖动模式** | **拖动画面**（不触发选字、不加载文字模型） | 拖动画面 |

`PicPage_MouseDown` 的处理顺序：中键 → 拖动；拖动模式下左键 → 拖动；其余左键 → 文字选择。

### 6.5 限制

- 页面整体小于可视区时没有可滚动空间，拖动无效（此时页面固定居中）。
- 拖动不改变缩放，和 Ctrl+滚轮可以自由组合（先放大到 300%，再慢慢拖动查看局部细节）。

## 7. 滚轮消息的路由（为什么需要消息过滤器）

`WM_MOUSEWHEEL` 只会投递给**当前拥有焦点的控件**。如果只在 `Form.WndProc` 里处理，
那么一旦用户点过工具栏按钮（焦点跑到按钮上），Ctrl+滚轮和滚轮滚动就会**整体失效**。

解决方案：进程级消息过滤器。

```csharp
// 构造时注册，窗口关闭时注销
_wheelFilter = new CanvasWheelMessageFilter(this);
Application.AddMessageFilter(_wheelFilter);      // OnFormClosed 中 RemoveMessageFilter
```

| 顺序 | 环节 | 行为 |
|------|------|------|
| 1 | `CanvasWheelMessageFilter.PreFilterMessage` | 拦截 `WM_MOUSEWHEEL` → 交给 `HandleCanvasWheel`；返回 `true` 表示已处理，消息不再派发 |
| 2 | `PdfPreviewForm.WndProc` | 兜底（正常情况下消息已在第 1 步被处理），调用同一个 `HandleCanvasWheel`，不会重复缩放 |
| 3 | 未处理 | 交给 `base.WndProc`，由默认逻辑处理（例如其它控件自己响应滚轮） |

`HandleCanvasWheel` 的判定与分派：

| 条件 | 处理 |
|------|------|
| 窗口已释放 / 不可见 / 没有焦点（`!ContainsFocus`） | 不处理，返回 `false` |
| 鼠标**不在**画布内且**没按** Ctrl | 不处理，交给默认逻辑 |
| 按着 **Ctrl** | 缩放（`ZoomAtPoint(1.15 或 1/1.15, 锚点)`）：鼠标在画布内用鼠标点作锚点，否则用画布中心 |
| 按着 **Shift** | 横向滚动：`ScrollCanvasHorizontal(-delta × 步长 / 120)` |
| 其它 | 纵向滚动：`ScrollCanvasBy(-delta × 步长 / 120)` |
| 滚轮增量为 0、未加载文档、系统设置「滚轮不滚动」(`MouseWheelScrollLines = -1`) | 吞掉消息，不做任何事 |

滚动步长按系统设置换算（每格滚轮）：

```
lines = SystemInformation.MouseWheelScrollLines
delta 高 16 位为 ±120（高精度滚轮可能是其它倍数，按比例换算）
lines = -1  → 不滚动
lines =  0  → 整页滚动：max(40, 画布高 - 20) 像素
lines =  N  → N 行：max(20, N × 20) 像素
```

## 8. 翻页与页面布局

| 环节 | 说明 |
|------|------|
| 渲染 | `_document.Render(页号, 宽, 高, 96, 96, false)` 生成位图，设给 `picPage` 并同步 `picPage.Size` |
| 页号范围 | `GoToPage` 自动夹在 `0 ~ PageCount-1`；渲染前也会再夹一次，防止文档被外部换掉 |
| 翻页后 | 滚动位置重置到 `(0, 0)`（回到页面左上角） |
| 位置 | `LayoutPage()`：页面比画布窄时水平居中（至少留 12 px 边距），比画布宽时靠左并出现水平滚动条；垂直方向始终从 12 px 处开始 |
| 尺寸变化 | `PnlCanvas_Resize` → 180 ms 防抖 → `ResizeTimer_Tick`：仅在 `FitWidth` / `FitPage` 模式下重新渲染；拖动窗口时不会每帧渲染 |
| 重入保护 | `_isRendering` 标志防止渲染过程中再次进入 `RenderPage` |

## 9. 文字选择与复制（PdfPig）

### 9.1 操作

| 操作 | 效果 |
|------|------|
| 左键拖拽 | 从按下点到当前点连选（按字符级插入符扩展） |
| 双击 | 选中鼠标下的**一个词** |
| 三击 | 选中鼠标下的**一整行** |
| `Ctrl+A` / 右键「全选本页文字」 | 选中当前页全部文字 |
| `Ctrl+C` / 右键「复制选中文字」 | 复制到剪贴板 |
| `Esc` / 右键「清除选择」 | 清除选择（`Esc` 在没有选择时才关闭窗口） |

### 9.2 实现要点

| 要点 | 说明 |
|------|------|
| 坐标来源 | `PdfPig` 读取每个字形（glyph）的边界框，换算成「左上角原点、Y 轴向下、单位 PDF 点」的阅读器坐标 |
| 与位图对齐 | 像素坐标 = PDF 坐标 × `_zoom`，所以缩放后选择框依然贴合（`ToPixelRectangle`） |
| 高亮绘制 | 直接画在 `picPage.Paint` 里：选中区域半透明蓝 `ARGB(70, 0, 120, 215)`；拖动时的插入符 1 像素线 `ARGB(210, 0, 90, 180)`（竖排文字的插入符画成横线） |
| 惰性解析 | 只在第一次需要选字时才建 `PdfTextSelectionModel`（`EnsureSelectionModel`），避免影响翻页速度 |
| 翻页 / 缩放 | 翻页 → 清空选择；缩放 → **保留**选择（PDF 坐标不变） |
| 光标 | 文字上显示 I 形光标，空白处显示箭头；拖动模式下手形 |
| 命中吸附 | `HitTestCaret` 允许一定吸附范围（横排按行高、竖排按列宽），点在文字空隙时不会立刻丢选 |
| 文字流方向 | 支持 `/Rotate 0/90/180/270` 页面：旋转页面上的横排文字在显示坐标中变成竖排，倒排文字按相反方向取阅读顺序 |
| 复制文本 | 跨行自动换行、行内词间距过大时补一个空格（`GetText`） |
| 鼠标捕获 | 拖选时 `picPage.Capture = true`，鼠标移出页面也能继续选；`MouseLeave` / `MouseUp` 负责收尾 |

## 13. 错误处理与健壮性

| 场景 | 表现 |
|------|------|
| 路径为空 | 直接返回，不做任何事 |
| 文件不存在 | 状态栏红字提示，不弹窗崩溃 |
| PDF 损坏 / 加密 / 无法渲染 | 关闭旧文档、标题变「读取失败」、状态栏红字 + 警告弹窗；窗口保持可用 |
| PDF 页数为 0 | 提示「该 PDF 没有可显示的页面。」 |
| 页面尺寸异常（≤ 0） | 提示「页面尺寸无效。」 |
| 单页像素过大 | 自动等比缩小到 2500 万像素以内再渲染 |
| PdfPig 打不开（文字层缺失 / 加密） | **只失去「选字」能力**，预览、缩放、拖动完全不受影响（`_textDocument = null`） |
| 复制到剪贴板被占用 | 红字提示「复制到剪贴板失败：...」 |
| 外部程序打开失败 | 红字提示「无法调用外部程序打开：...」 |
| 文件被其它步骤移动 / 删除 | PdfPig 打开文件时使用共享读写 + `FileShare.Delete`，预览期间其它处理步骤仍可移动该 PDF；`外部程序打开` 前会先 `File.Exists` 检查 |

## 16. 已知限制与注意事项

1. **单页显示**：一次只渲染一页，没有「连续滚动」视图；换页后滚动位置回到左上角。
2. **页面小于视口时只能居中**：此时 Ctrl+滚轮表现为居中缩放，无法把锚点移到光标处（没有可滚动空间）。
3. **缩放锚点存在 1～2 px 级误差**：极端情况下滚动条出现 / 消失会改变可视区宽度，已做 2 次校正，仍可能有极小偏差。
4. **高精度滚轮**（`delta` 不是 120 的整数倍，例如精密触控板）：按比例换算步长，但不做亚像素累积。
5. **100% 不等于打印尺寸**：100% 是 96 DPI 屏幕像素比例，打印机 DPI 不同则实际输出尺寸不同；需要精确尺寸请用「外部程序打开」。
6. **无打印 / 查找 / 批注 / 连续页面**：这些功能请用「外部程序打开」交给 Adobe Reader 等程序。
7. **只读**：本窗口不会保存、修改或加密 PDF；所有选择、缩放、拖动状态都只存在内存中。
8. **内存**：每页位图按当前缩放重新分配，极端放大受 2500 万像素上限保护；关闭窗口时统一释放位图、pdfium 文档、PdfPig 文档与文件流。
