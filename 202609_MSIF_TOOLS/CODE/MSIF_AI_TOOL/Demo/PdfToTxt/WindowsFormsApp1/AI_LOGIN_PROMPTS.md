# AI 数据登录话术手册（指挥模板）

对着 AI 直接说下面这些话即可。把【】中的内容换成实际值，其余照抄。

## 四个接口与对应表

| 表 | 接口脚本 | 表内容 |
|----|----------|--------|
| part_basic_info | PART_BASIC_INFO_API.py | 部品基本信息表 |
| part_code_ref | PART_CODE_REF_API.py | 部品コード参照表 |
| proc_drawing_ref | PROC_DRAWING_REF_API.py | 要領図参照表 |
| title_block | TITLE_BLOCK_API.py | タイトルブロック（**每図番号 1 行**，含改訂履歴 rev1~rev5） |

四个接口均为 JSON CLI，支持 insert-many --replace（幂等，可重复执行）、
upsert / update / delete / query / count / clear / schema，
默认数据库 `図面\db\zumen_data.sqlite`，无需指路径。

## 一、登录数据（最常用）

### ① 登录一张图纸的一张表

```
从 図面\xy\【図番号】_xy.txt 识别【表名】数据，调用【接口脚本】insert-many --replace 登录到数据库，登录后用 query --zumen 【図番号】 验证。部品コード中的 □□/△△/○○ 替换为 □；本来就是单个 □ 的（如 MZA□968）保持原样。
```

示例（要領図参照表，把図番号换掉即可用）：

```
从 図面\xy\H310U10004_xy.txt 识别要領図参照表数据，调用 PROC_DRAWING_REF_API.py insert-many --replace 登录，然后 query --zumen H310U10004 验证。□□/△△/○○ 替换为 □。
```

### ② 一张图纸的全部表一次登录

```
从 図面\xy\【図番号】_xy.txt 识别数据，把部品基本信息表、部品コード参照表、要領図参照表、タイトルブロック全部登录入库（都用 --replace 幂等方式），登录完逐表 query 验证并汇报行数。□□/△△/○○ 替换为 □。
```

> title_block 登录要点：每図番号只有 1 行，改訂履歴从新到旧填 rev1 → rev5
> （每行 no/sub/date/person/request_no/content 六字段，不足 5 行的留空）。
> 同行多个文字按 X 顺序无空格拼接；承認者多个名字以逗号分隔。


### ③ 批量登录多张图纸

```
図面\xy\ 下有【図番号1】、【図番号2】、【図番号3】三张图纸，逐张识别并登录【表名】数据（--replace 幂等），全部完成后按図番号汇总行数。
```

或者全目录：

```
把 図面\xy\ 目录下所有 xy 文件的【表名】数据都登录入库，最后汇总各図番号行数。
```

## 五、Excel 部品表填充（部品名同名匹配）

场景：已有一个 Excel 部品表模板（部材名等列已有内容），要把数据库 part_basic_info
的数据按「部品名同名匹配」填进模板既有行。

```
我有一个 Excel 部品表：【Excel 文件路径】（工作表默认第 1 个；表头 13 列：
部材名｜部品名｜区分｜数量｜切断寸法｜部品ｺｰﾄﾞ｜参照元｜H下限｜H上限｜W下限｜W上限｜使い分け｜特注；部材名等列已有内容）。

请用 PART_BASIC_INFO_API.py query --zumen 【図番号】 读取数据库 part_basic_info 数据，
按「部品名同名匹配」填入 Excel，规则如下：

1. 匹配键：Excel 的「部品名」列 == 数据库的 part_name（原文精确匹配，仅去首尾空格，
   不做全角/半角转换）。
2. 命中 1 条数据库记录：在该 Excel 行填入
   区分←frame_class（枠区分）、数量←quantity、切断寸法←cut_dim、部品ｺｰﾄﾞ←part_code；
   只填空白单元格，已有内容的单元格一律不覆盖。
3. 同一部品名对应多条数据库记录（部品ｺｰﾄﾞ或枠区分不同，如「部品セット」MZA□968/MZA674）：
   第 1 条填入匹配行，其余紧随其后插入新行（部材名/部品名复制自匹配行，其余列同规则 2 填入）。
4. 数据库有、模板没有的部品名：追加到数据区末尾（部材名留空，其余列同规则 2 填入）。
5. 模板有、数据库没有的部品名：该行保持原样不动。
6. 除 区分/数量/切断寸法/部品ｺｰﾄﾞ 四列外，其余所有列
   （含部材名、参照元、H下限、H上限、W下限、W上限、使い分け、特注）一律不改动。
7. 另存为新文件【新文件路径，如 …_H310U10004更新.xlsx】，原模板文件不动。
8. 完成后汇报：命中行数、多匹配展开行数、追加行数、两边未匹配的部品名清单，
   并抽查 3 行确认与 query 结果一致。
```

要点：列以第 1 行表头文字定位；若模板表头与上述 13 列名存在全角/半角差异，
按模板实际表头对应，并在汇报中说明。

### ⑤ 补充：参照元列填図番号

注意：上面模板的规则 6 把「参照元」列为「一律不改动」，所以要填参照元时必须
明确说明「覆盖原规则 6 中关于参照元的部分」，否则 AI 会跳过该列。

追加指令（任务进行中/刚完成时接着说）：

```
接着刚才的 Excel 填充任务，补充一条规则（覆盖原规则 6 中关于参照元的部分）：
「参照元」列的值 ← 该图纸的図番号。図番号从 図面\xy\【図番号】_xy.txt 中识别（本图为【図番号】）。
凡是本次从数据库填入数据的行（命中行、多匹配展开的插入行、末尾追加行），
其「参照元」列一律填【図番号】。
参照元同样只填空白单元格，已有内容不覆盖（如需统一覆盖请明确说「全部覆盖为…」）。
其余列（部材名、H下限、H上限、W下限、W上限、使い分け、特注）仍一律不改动。
改完后保存，汇报参照元共填了几行，并抽查 3 行确认已填【図番号】。
```

示例（H310U10004）：把上面所有【図番号】换成 H310U10004 即可。

要点：
- 写入范围要选清楚：默认「仅本次从数据库填入的行」；如需整表所有数据行都填，
  改为「数据区内所有行」。
- 是否覆盖已有值要选清楚：默认「只填空白单元格」；统一覆盖需明说。

## 话术要点（写清楚这 6 点就不容易出偏差）

1. **数据来源**：哪个 xy 文件（或直接给数据）
2. **目标表**：part_basic_info / part_code_ref / proc_drawing_ref / title_block
3. **図番号**：明确写出来
4. **动作词**：登录（= insert-many --replace）/ 查询 / 更新 / 删除 / 清空
5. **替换规则**：□□/△△/○○ → □（仅普通部品コード；单个 □ 保持原样）
6. **验证要求**：登录后 query 验证、汇报行数

> 说明：--replace 幂等意味着同一指令重复执行也不会产生重复数据，
> 所以「登录」类指令可以放心多次下达。
